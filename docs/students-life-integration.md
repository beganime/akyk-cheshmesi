# Интеграция Akylchat со Students Life

Akylchat является единственным сервером чата между клиентом и менеджером.
Students Life хранит только локальный кеш сообщений и push-токен устройства.

ManagerSL будет создавать прямой чат после одобрения анкеты. Идемпотентный
ключ операции — `SL-ID`; повторный запрос должен вернуть существующий чат.

До появления общего диска вложения сохраняются в persistent volume
`media_data`. В проекте уже предусмотрен переход на S3 через `USE_S3`, поэтому
модели и API при смене провайдера изменять не потребуется.

Срок хранения рабочих чатов — 90 дней. Автоматическое удаление выключено по
умолчанию: перед включением необходимо реализовать push-предупреждение, дать
три дня на реакцию и исключить финансовые/аудиторские данные из удаления.
